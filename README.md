# AI Chatbot with Voice Replies
Overview
This project is an AI-powered chatbot that replies to users using both text and voice.
It uses OpenAI API for generating responses and Text-to-Speech (TTS) for converting them into audio.

Features
Text and voice-based chatbot
AI-generated natural responses
Uses gTTS / pyttsx3 for voice output
Simple and user-friendly Python interface

Tech Stack
Python
OpenAI API
gTTS / pyttsx3
Tkinter / Streamlit
